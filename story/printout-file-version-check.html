회의 자료를 출력하기 전, 최신 파일인지 확인하세요

히마와리 편집팀
회의 준비자료 출력No.194L

회의 전날 내려받은 자료를 아침에 출력했는데, 밤사이 수정본이 올라올 때가 있습니다. 파일 이름에 최종이라는 말이 붙어 있어도 어느 시점의 내용인지 다시 봐야 합니다. 가방에 종이 자료를 넣기 전에 출력할 파일을 직접 열어보세요.

마지막 안내와 파일을 대조하기

자료를 만든 사람이 지정한 최신 파일이나 공유 위치를 확인합니다. 예전에 받은 첨부 파일을 그대로 열기보다 마지막 수정 안내와 비교해보세요. 수정 날짜는 참고할 수 있지만, 그것만으로 내용이 맞는지는 알 수 없습니다. 바뀌었다고 안내된 표나 문장을 실제 파일에서 찾아 읽습니다.

종이에서도 버전을 찾을 수 있게

자료를 준비하는 사람이라면 제목 옆에 회의 날짜나 버전 표시를 남깁니다. 받은 자료에 그런 표시가 없다면 파일 이름과 확인한 시점을 별도 메모에 적어두세요. 참석자마다 다른 자료를 펼쳤을 때 서로 무엇을 보고 있는지 대조할 수 있습니다. 업무에서 정한 표시 방식이 있다면 그 방식을 따릅니다.

출력한 뒤에는 한 장씩 보기

첫 장만 확인하고 묶기 전에 페이지 순서와 끝장을 살펴봅니다. 표가 다음 장으로 잘리거나 필요한 페이지가 빠졌는지도 봅니다. 새로 출력한 몇 장을 예전 묶음 사이에 끼우는 경우에는 교체할 페이지를 정확히 빼주세요. 같은 페이지 번호의 옛 내용이 뒤에 남아 있으면 회의 중 다시 헷갈릴 수 있습니다.

옛 자료는 가져갈 묶음에서 빼기

다 쓴 초안은 오늘 가져갈 파일과 구분합니다. 보관과 폐기는 업무 자료의 취급 기준에 맞춰 처리하세요. 회의에서 내용을 다시 고쳤다면 종이의 메모가 어느 파일에 반영됐는지 확인한 뒤 정리합니다.

자주 묻는 질문

파일 이름에 최종이라고 쓰여 있으면 그대로 출력해도 되나요?

마지막 안내에서 지정한 파일인지 확인하고, 바뀐 내용도 직접 열어 읽어보세요. 이름이나 수정 날짜만으로 최신 내용을 판단하지 않습니다.

종이 몇 장만 새로 출력할 때는 무엇을 확인하나요?

교체할 페이지를 정확히 빼고 새 페이지의 순서와 번호를 맞춰주세요. 같은 번호의 옛 페이지가 묶음에 남지 않았는지도 봅니다.
