뜨개 도안의 전체 단수와 반복 위치를 따로 적기

히마와리 편집팀
뜨개 도안진행표취미 모임

뜨개 도안의 반복 구간을 진행하다 멈추면 숫자 하나로 위치를 남기기 어려울 때가 있습니다. 작품 전체에서 몇 단을 마쳤는지와 반복 구간의 어디까지 왔는지가 서로 다른 정보이기 때문입니다. 노트에 '14'라고만 적으면 전체 단수인지 반복 안의 줄인지 다시 해석해야 합니다. 두 위치를 따로 쓰고 다음에 할 부분까지 문장으로 남겨봅니다.

시작할 때는 도안이 쓰는 말부터 확인합니다. 전체 단수에 어느 부분이 포함되는지, 반복의 줄 번호가 어떤 범위를 가리키는지 해당 안내를 읽습니다. 평소 다른 도안에서 쓰던 표현과 같다고 생각하지 않습니다. 기록표의 제목을 도안과 맞추면 모임에서 질문할 때도 어느 부분을 말하는지 짚기 쉽습니다. 불명확한 계산은 추측해 맞추기보다 확인할 질문으로 남깁니다.

완료한 숫자와 다음에 할 숫자

표에는 '전체 완료 단수'와 '반복 회차·완료 줄'처럼 항목 이름을 붙입니다. 완료한 위치를 적는지 다음에 할 위치를 적는지도 정해야 합니다. 둘을 같은 칸에서 번갈아 쓰면 예전 체크를 보고 한 줄 더 진행할 수 있습니다. 완료한 위치는 표에, 다음 시작은 아래 문장에 두는 방법을 시도할 수 있습니다.

계산을 이해하기 위한 가상 예를 들어봅니다. 시작 부분 8단을 마친 뒤 네 줄짜리 구간을 반복한다고 가정합니다. 첫 반복의 네 줄을 모두 마치고 둘째 반복의 두 줄을 끝냈다면, 이 예에서 전체 완료 단수는 8에 4와 2를 더한 14단입니다. 반복 안의 위치는 둘째 회차의 2줄 완료로 적을 수 있습니다. 이는 특정 작품을 뜨는 도안이 아닙니다.

가상 예의 기록 항목현재 표시
시작 부분 완료8단
반복 구간4줄짜리 반복
전체 완료 단수14단
반복 안에서 완료2회차의 2줄
다음 시작 메모2회차의 3줄부터 확인

숫자를 둘로 적는 이유는 같은 위치를 서로 다른 기준으로 찾기 위해서입니다. 전체 기록을 보면 작품이 어디까지 진행됐는지 볼 수 있고, 반복 위치를 보면 다음에 읽을 줄을 찾을 수 있습니다. 실제 작업에서는 도안의 구분을 따릅니다. 시작 부분을 세는 방식이나 반복의 시작점이 다르면 위 예의 숫자를 그대로 적용하지 않습니다.

체크는 한 줄의 작업을 마친 뒤 남기는 방식으로 정해볼 수 있습니다. 다만 도안이 사용하는 진행 표시나 모임의 안내가 있으면 그에 맞춥니다. 숫자가 맞아 보인다는 이유로 실제 작업을 확인하지 않고 다음 줄로 넘어가지 않습니다. 메모의 위치와 작업물의 상태를 같이 보아야 기록을 잘못 남긴 경우도 알아볼 수 있습니다.

줄 중간에서 멈춘 상태를 남기기

완료하지 못한 줄을 체크해야 할지 고민될 때는 '중간에 멈춤'이라고 적을 수 있습니다. 어느 위치를 다음에 확인해야 하는지 도안에서 사용하는 기준대로 기록합니다. 줄을 다 마쳤다는 표시와 중간 상태를 같은 숫자로 쓰지 않는 것이 중요합니다. 정확한 상태를 설명하기 어려우면 확인할 부분을 적고 모임에서 도움을 받아 대조하세요.

이 글에 함께 소개한 Himawari No.200 제품 정보는 뜨개 모임에 들고 갈 가방을 살펴볼 자료입니다. 작업물을 정리하기 전에 진행표부터 적어두면 가방을 풀어 다시 시작할 때 볼 기준이 남습니다. 도구를 정해둔 방법으로 보관한 뒤 노트와 현재 도안의 짝을 맞춰두세요. 기록이 필요한 순간을 귀가 뒤로 미루지 않는 흐름입니다.

날짜와 도안의 페이지도 남겨볼 수 있습니다. 노트에 여러 작품의 숫자가 섞이면 어떤 표가 현재 작업인지 찾기 어려울 수 있으므로 작품 이름을 앞에 적습니다. 작품을 두 개 진행한다면 각각의 기록 자리를 나눕니다. 라벨이나 작업 사진을 함께 보관하더라도 단수 기록이 어디에 있는지 알아볼 수 있게 정리합니다.

다음에 시작할 때는 마지막 날짜의 기록을 먼저 읽고 실제 작업 상태와 대조합니다. 숫자 옆에 '완료'와 '다음'이라는 이름이 있는지 확인하면 어디서 시작할지 판단하기 쉽습니다. 노트를 보고도 상태가 맞지 않으면 그대로 진행하지 말고 어느 부분부터 다시 확인할지 정합니다. 도안의 설명을 찾아 읽거나 모임에서 같은 위치를 짚어 질문할 수 있습니다.

풀어서 돌아갔다면 표도 함께 돌아가기

작업 일부를 풀어 되돌아갔다면 기록도 현재 위치로 고칩니다. 이전 숫자 위에 새 숫자를 덮어 쓰기보다 취소 표시를 하고 새 줄에 적는 방법이 있습니다. 돌아간 위치와 수정 날짜가 보이면 어느 기록이 유효한지 알아보기 쉽습니다. 실제로 어떻게 되돌릴지는 사용하는 작업법의 안내를 따르고, 여기서는 기록을 바꾸는 순서만 다룹니다.

가상 예에서 14단으로 적었던 작업을 더 앞의 위치로 되돌렸다면 전체 완료 단수와 반복 위치를 모두 다시 확인합니다. 한쪽 숫자만 고치면 두 항목이 같은 상태를 가리키지 않게 될 수 있습니다. 다음 시작 메모도 함께 갱신하세요. 완료 체크를 지운 뒤 예전의 '다음' 문장을 남겨두는 일이 없는지 읽어보면 됩니다.

반복 구간이 끝나 새로운 구간으로 넘어가면 표의 범위도 바꿉니다. 예전 반복표 아래에 같은 숫자를 이어 적기보다 새 구간 이름을 쓰고 사용 중인 도안의 페이지를 붙입니다. 전체 단수는 계속 기록할 수 있지만 구간 안의 번호는 새 기준이 됩니다. 기록의 제목이 바뀌어야 같은 '2줄'이라는 값이 무엇을 말하는지 알 수 있습니다.

진행표가 복잡해졌다면 현재 위치와 다음에 할 부분을 새 표로 옮길 수 있습니다. 이전 기록은 참고용으로 남기고, 새 표의 값이 실제 작업 상태와 맞는지 확인합니다. 도안의 중요한 설명을 임의로 줄여 다른 뜻이 되지 않도록 필요한 표현은 그대로 적습니다. 표를 보기 좋게 정리하는 일이 작업의 위치를 바꾸는 일은 아닙니다.

모임을 마칠 때에는 마친 줄을 확인하고 다음 줄을 문장으로 남깁니다. 도안의 구간 이름과 완료한 위치, 아직 확인할 질문이 서로 구분되어 있으면 됩니다. 숫자를 정확히 적었다고 생각한 날에도 작업물과 한 번 대조하세요. 다음에 펼칠 기록에는 전체 진행과 반복 안의 위치가 함께 남고, 그 아래에 시작할 곳이 읽혀야 합니다.
