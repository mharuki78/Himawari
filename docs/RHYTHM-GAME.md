# Pack the Beat — No.1884

2026-10-01 사용자 요청: 1884 가방에 물건을 박자에 맞춰 넣는 리듬게임, 완성도 있는 로딩 화면, 점수별 쿠폰 지급.

## 화면과 플레이

- 세이지 종이(#F3F7EF), 딥 그로브(#4F6B58), 잉크(#294C40), 세이지 미스트(#E3EFE0), 지퍼 골드(#DFC783). 사이트의 Pretendard/Manrope 계열과 굵은 영문 제목, 고정폭 숫자를 사용한다.
- 대표 요소는 실물 1884 원본을 참조한 투명 가방 그래픽과 한 줄의 낙하 물건. 출근·산책·여행 장면은 플레이 8마디마다 바뀐다.
- 로딩은 이미지 decode, 음악 다운로드/decode, 쿠폰 조회의 실제 진행을 표시한다. 실패하면 같은 위치에서 재시도할 수 있다.
- 직접 작곡한 `Pocket Day`, 108 BPM, 24마디와 카운트인·아웃트로, 총 약 57초. `scripts/build-rhythm-audio.mjs`의 독립 합성음과 ffmpeg MP3 인코딩을 사용하며 외부 음악·샘플은 없다.
- 물건은 탭, 지퍼는 누르고 끝에서 놓기. 터치/마우스와 Space/Enter가 같은 판정을 사용한다. Perfect ±65ms, Good ±145ms, 그 밖은 Miss. 점수는 총 판정 단위 대비 10,000점으로 환산한다.
- Web Audio 재생 시각이 음악·노트의 공통 시계다. 문서가 숨겨지거나 창이 포커스를 잃으면 자동 정지한다. native dialog 안에 게임판과 조작기를 고정하며 Escape는 먼저 일시정지한다.
- 12초 연습은 쿠폰 없이 사용할 수 있다. 타이밍 보정은 ±150ms, 8회 탭의 중앙값 또는 슬라이더로 설정한다. 모션 감소에서는 배경의 박자 효과와 물건 삽입 장식을 줄이고 플레이에 필요한 노트 이동은 유지한다.

## 쿠폰과 검증

2026-10-01 사용자 결정: 게임만 먼저 공개하고 쿠폰 지급은 보류한다. 운영 프로모션의 비활성 상태를 보존하고 화면에는 예정 혜택 및 이벤트 준비 중 안내를 표시한다.

- `/api/games/rhythm/start`: Same-Origin POST, 브라우저 HttpOnly 쿠폰 소유 쿠키에 연결된 HMAC 서명 세션과 서버 seed를 반환한다.
- `/api/games/rhythm/finish`: Same-Origin POST, 최대 65,536 bytes. 브라우저 점수는 사용하지 않는다. 공유 `rhythm-core.mjs`로 입력 기록을 다시 계산한다. 서명, 버전, 소유자, 최소 완주 시간, 15분 유효기간, 입력 수·순서·범위와 반복 누름을 검사한다.
- 5,000 무료배송 / 6,500 10% / 8,000 15% / 9,200 20%. 기존 관리자 프로모션 중 현재 활성인 가장 좋은 해당 쿠폰 한 장만 발급한다. 프로모션 설정을 변경하지 않는다.
- 이 브라우저에서 한국 날짜 기준 하루 한 장, 사용 전에 높은 혜택으로 업그레이드할 수 있다. SQL은 낮은 점수로 혜택을 덮어쓰거나 사용 완료 쿠폰을 재발급하지 않는다. 같은 소유자·날짜·쿠폰의 토큰은 결정적이므로 네트워크 재시도로 무효화되지 않는다.
- 서버가 발급한 토큰만 기존 쿠폰 지갑 및 게임 선호 쿠폰에 저장한다. 발급 실패를 획득 성공으로 표시하지 않고 결과에서 재시도한다. 주문서와 주문 API의 조건·만료·일회 사용 검증을 재사용한다. 자사몰 무통장 주문 전용이다.
- 브라우저의 입력 기록은 서버에서 검증하지만 자동 입력 프로그램을 완전히 증명·차단하는 구조는 아니다. 사용자별 본인 인증이나 기기 변경 제한을 새로 추가하지 않는다.
