# 2026 제품 가이드북 반영 기록

- 원본: 사용자가 제공한 가격 없는 GuideBook.pdf (67페이지)
- 공개 경로: /assets/guides/himawari-guidebook-2026.pdf
- 전역 상단 메뉴: 가이드북 (PDF, 새 탭)
- 운영 카탈로그: revision 41 → 42, 96개 상품 소재·사양 반영, 그중 89개 외부 크기 반영
- 기존 가격, 재고, 옵션, 사진 등 사양 외 필드 보존 확인
- 사양 출처 페이지를 measurementNote에 기록. 노트북 포켓의 미기재 두께와 인치 호환은 추정하지 않음
- 추가 체스트벨트 세트는 가방 본체 기준임을 명시

## 추가 확인 필요

- 1884 일반형이 가이드북 1884L인지 확인. 블랙M(store-13641866477)은 1884M 규격 반영
- 사이트 1084H와 가이드북 H1084 동일 모델 여부
- 0514 일반형 높이: 사양표 45cm / 도면 43cm
- 0514S 폭: 사양표 1cm / 도면 14cm
- 0424는 가이드북에 있으나 운영 카탈로그에 없어 자동 상품 생성하지 않음
- 가이드북에 없는 모델은 기존 정보 유지

## 유지 관리

원문 전사 및 매칭: data/guidebook-specs-2026.json. 임포트 도구 scripts/import-guidebook-specs.mjs는 기본 미리보기이며 --apply에서만 저장. 정확한 모델/상품 ID로 매칭하고 기존 사양 충돌 시 저장 중지. 운영 ETag 조건부 저장과 백업 사용. 새 사용자 확인 정보가 들어오면 매핑과 관련 상품 사양을 함께 검토할 것.
