## 운영 전환에 남은 항목

1. 네이버 개발자 로그인 후 새 콜백 등록. 구글은 새 원본/콜백 및 홈페이지·개인정보·약관 링크를 추가하고 저장 완료 확인. Google OAuth 앱은 현재 테스트 게시 상태여서 일반 고객 공개 전 운영 게시 검토가 필요. 이후 PUBLIC_SITE_URL 및 구 도메인 리디렉션을 함께 적용하고 소셜 로그인 검증. 현재 운영 env/redirect 미전환.
2. PG 계약/심사 후 제공자 선택, 승인·웹훅·취소·부분환불·중복 승인 방지·실거래 검증. 현재 코드에서 실제 승인을 생성하지 않음.
3. 발신 도메인 인증/메일 키, 백업 암호화 키와 정기 실행 환경, 외부 가용성 감시 통보 채널.
4. 실제 실측 자료/호환 구성품/수선 조건 입력, Smartstore 커머스 API 권한 및 재고 운영 방식. 현재 재고는 자사몰 할당 재고로 운영하고 자동 동기화로 표시하지 않음.
5. 미결제 단계에서는 재고를 예약하지 않으므로 미결제 재고 해제 대상이 없음. 주문 자동 만료 시각은 PG 승인 세션 만료 정책 확정 후 연결해야 하며 기존 대기 주문을 임의 취소하지 않음.
