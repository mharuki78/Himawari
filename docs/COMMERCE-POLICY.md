## 상품과 주문 화면

- 공개 카탈로그에 등록된 항목은 실물 가방 상품이다.
- 관리자 상품 카탈로그를 서버에서 읽어 상품 목록과 개별 상세페이지 HTML에 제품명, 가격, 이미지, 설명과 구매 링크를 먼저 렌더링한다.
- 자사몰 판매가는 관리자가 확인해 입력한 네이버 할인 적용 가격과 동일하게 표시하며, 네이버 할인율은 확인된 값만 함께 표시한다.
- 자바스크립트를 실행하지 않는 심사 도구에서도 판매 상품을 확인할 수 있어야 한다.
- `바로 구매하기`는 자사몰 내부 주문서로 연결하고, 장바구니 상품도 같은 주문서에서 주문을 접수한다.
- 내부 주문서는 관리자가 활성화한 무료배송·10%·15%·20% 쿠폰 중 한 장을 선택할 수 있고, 서버가 주문 접수 시 조건과 금액을 다시 계산한다.
- PG 연결 전 주문은 결제를 실행하지 않고 `결제 대기`로 저장한다. 결제 완료나 출고 완료로 오인되는 버튼과 문구는 노출하지 않는다.
- 결제 승인·자동 취소·자동 환불·재고 차감은 아직 제공하지 않는다. 상세 상태와 권한은 `docs/ORDER-POLICY.md`를 따른다.
- Npay 주문형은 자사몰 내부 결제 대기 주문과 분리된 공식 SDK v2.1 버튼으로 제공한다. 상품 목록에는 표시하지 않고 각 상품 상세에 Npay 구매·네이버쇼핑 찜을 표시하며, 장바구니에는 담긴 상품의 Npay 구매만 표시한다. 오픈 승인 전 검수 링크는 비공개 세션을 만든 뒤 실제 운영 상품 상세 URL로 이동하고 그 세션에서만 Sandbox를 사용한다.
- Npay 주문 등록과 상품 정보 응답은 현재 공개 카탈로그의 상품명·가격·이미지를 서버에서 다시 읽는다. 클라이언트가 보낸 가격과 상품 설명은 결제 금액에 사용하지 않는다.
- Npay 상점 ID, 인증키, 버튼 인증키가 모두 설정된 배포에서만 버튼을 노출한다. 인증키는 서버 응답·로그·브라우저 저장소에 공개하지 않으며, 버튼 인증키만 공식 SDK 초기화에 전달한다.
- Npay 상품 정보 연동 URL은 `https://himawari.co.kr/api/npay/product-info`를 사용한다.

## 배송·청약철회 기준

- 배송사는 로젠택배이며 결제 완료 후 영업일 기준 2일 이내 출고한다.
- 기본 배송비는 3,500원이며 상품 구매금액 100,000원 이상은 무료배송한다.
- 수령일부터 7일 이내 청약철회가 가능하다는 기준을 안내한다.
- 표시·광고와 다르거나 계약과 다르게 이행된 경우 수령일부터 3개월 이내 또는 그 사실을 안 날부터 30일 이내 신청할 수 있음을 안내한다.
- 단순 변심의 반환 비용은 구매자가, 상품 하자나 오배송의 반환 비용은 판매자가 부담한다.
- 반품 주소는 `경기도 시흥시 배곧4로 32-29, 파크뷰 206호 히마와리 코리아`이다.
- 사용자가 제공한 편도·왕복 반품비는 8,000원으로 표시한다.
- 반품은 임의 발송 전에 비공개 문의 또는 Npay 주문내역을 통해 먼저 접수하도록 안내한다.

## Npay 정식 오픈 (2026-09-11)

사용자가 네이버페이센터 최종 승인 완료를 확인하고 전 상품 공개를 요청했다. 운영 환경에서 NPAY_PUBLIC_ENABLED=true, NPAY_ENV=production을 사용한다. 회원 로그인 여부와 무관하게 판매 상품 상세의 공식 Npay 버튼과 상품이 담긴 비회원 장바구니 버튼을 표시한다. 품절 및 필수 옵션 검증은 유지한다. 과거 검수 쿠키·토큰은 공개 오픈 이후 Sandbox를 선택하지 못한다. 네이버의 대표 도메인 변경 확인 후 가맹점 상품 정보 URL과 공통 유입 스크립트를 himawari.co.kr 기준으로 전환했다.
