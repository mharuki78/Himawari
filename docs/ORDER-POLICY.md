# Himawari 자사몰 주문 운영 정책

이 문서는 2026년 9월 3일 사용자가 요청한 자사몰 주문서, 고객 취소·환불 요청, 관리자 주문관리 기능의 운영 경계를 기록한다.

## 주문과 결제 경계

- 공개 상품의 `바로 구매하기`는 Himawari 내부 `checkout.html` 주문서로 연결한다.
- 주문은 회원가입 없이도 접수할 수 있다. 로그인 회원의 주문은 회원 계정에 연결하고, 비회원 주문은 회원 식별자 없이 받는 분 정보와 주문번호로 보관한다. 상품명, 모델, 대표 이미지, 단가와 수량은 주문 시점 값으로 저장한다.
- 상품금액은 현재 카탈로그의 네이버 할인 적용 가격과 동일한 자사몰 단가로 계산한다. 기본 배송비 3,500원과 쿠폰 적용 전 상품금액 100,000원 이상 무료배송 기준은 서버가 다시 계산한다.
- 주문에는 무료배송, 10%, 15%, 20% 중 관리자가 활성화한 쿠폰 한 장만 적용할 수 있다. 할인율 쿠폰은 상품금액에 적용하고 무료배송 쿠폰은 기본 배송비만 면제한다. 최소 주문금액, 최대 할인금액과 종료 일시는 관리자 설정을 따르며 주문 접수 시 서버가 다시 검증한다.
- 쿠폰 ID, 표시명과 실제 할인액은 주문 당시 값으로 저장한다. 이미 접수된 주문 금액은 이후 프로모션 변경의 영향을 받지 않는다.
- No.0422 미니게임은 점수에 따라 관리자가 활성화한 쿠폰 한 장을 현재 브라우저에 획득 쿠폰으로 저장한다. 주문서는 저장된 쿠폰이 여전히 활성 상태이고 최소 주문금액을 충족할 때 이를 자동 선택하며, 사용자는 다른 활성 쿠폰이나 쿠폰 미사용으로 바꿀 수 있다.
- 게임 결과는 쿠폰 발급 권한이나 최종 할인 승인을 대신하지 않는다. 주문 접수 시 서버가 쿠폰의 활성 상태, 주문금액 조건, 할인 한도와 종료 일시를 동일하게 다시 검증한다.
- PG가 연결되기 전에는 결제를 실행하지 않는다. 새 주문은 `결제 대기`로만 접수하고 결제 완료나 출고 완료로 표시하지 않는다.
- 주문 접수는 결제 완료가 아니며, 관리자의 `주문 확인` 상태 변경이 판매 가능 여부 확인과 주문 승낙을 나타낸다.

## 상태와 권한

- 고객은 `결제 대기`, `주문 확인`, `배송 준비` 단계에서 취소를 요청할 수 있다.
- 고객은 `배송 중`, `배송 완료` 단계에서 반품·환불 검토를 요청할 수 있다.
- 고객 요청은 각각 `취소 요청`, `반품·환불 요청` 상태이며 실제 완료를 의미하지 않는다.
- 관리자는 서버 인증 후에만 상태, 로젠택배 운송장 번호와 내부 메모를 변경할 수 있다.
- `배송 중` 변경에는 운송장 번호가 필요하다.
- `취소 완료`와 `환불 완료`는 관리자 확인 대화상자를 거친다. `환불 완료`는 외부에서 실제 환불이 끝난 경우에만 기록한다.
- PG가 연결되기 전에는 결제 승인, 자동 취소·환불 또는 자동 배송 통지를 제공하지 않는다. 자사몰 재고는 관리자가 실제 주문을 확인해 `주문 확인`으로 변경할 때 예약하고, `취소 완료`·`환불 완료`에서 자동 복원한다. Npay 주문 재고는 주문관리 API의 고정 IP 연결 전까지 Npay 센터에서 별도로 확인한다.

## 개인정보와 기록 보존

- 주문 이행과 상태 안내를 위해 받는 분 이름, 이메일, 전화번호, 우편번호, 주소와 배송 요청사항을 수집한다.
- 주문 기록은 회원 프로필·장바구니·관심상품과 별도 테이블에 저장한다. 전체 주문은 관리자 인증 요청에서만 읽고, 로그인 회원은 자신의 계정에 연결된 주문만 읽는다. 비회원 주문은 공개 조회 API를 제공하지 않으며 고객은 주문번호와 접수 때 입력한 연락정보로 비공개 문의를 남긴다.
- 회원탈퇴 시 로그인 연결, 세션, 장바구니와 관심상품은 삭제한다. 계약 또는 청약철회, 대금결제와 공급에 관한 거래 기록은 전자상거래법상 보존 의무를 위해 분리하여 5년 보관한 뒤 삭제 대상으로 처리한다.
- 주문 상태 변경은 행위자, 상태, 시각과 메모를 이력으로 보존한다. 관리자 내부 메모는 고객 화면에 공개하지 않는다.

## 확인 근거

- 사용자 확정 배송 기준과 사업자 정보: `docs/COMMERCE-POLICY.md`
- 전자상거래 등에서의 소비자보호에 관한 법률 제6조 및 같은 법 시행령 제6조: 계약·청약철회와 대금결제·공급 기록 5년, 소비자 불만·분쟁 처리 기록 3년
- 개인정보 보호법 제21조: 목적 달성 또는 보유기간 경과 시 파기, 다른 법령에 따른 보존 시 별도 저장·관리

이 정책은 법률 자문 또는 PG 연동 완료를 의미하지 않는다. 실제 결제수단을 추가할 때 결제 승인·실패·취소·환불·웹훅과 재고 상태 계약을 별도로 확정해야 한다.

## 2026-09-11 구매 방식 변경

사용자 요청에 따라 바로 구매하기는 Npay와 무통장입금 선택 화면으로 연결한다. Npay는 공식 SDK를 통해 네이버 주문서로 이동한다. 내부 주문서는 무통장입금 전용이며 payment_method=bank_transfer, payment_pending(고객 표시: 입금 대기)로 접수한다. 운영자는 실제 입금을 확인한 뒤 기존 주문 확인 절차를 진행한다. 계좌는 사용자가 제공한 은행명·계좌번호·예금주만 사용하고, 미설정 시 클라이언트와 서버 모두 무통장 주문을 차단한다. 자사몰 쿠폰은 내부 무통장 주문에만 적용된다.
