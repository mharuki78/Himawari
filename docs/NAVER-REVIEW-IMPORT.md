# 네이버 리뷰 가져오기

2026-09-10 전 제품·전 기간 리뷰 251개를 운영 DB에 가져왔다. 네이버 전시상태를 따라 정상 250개는 공개하고 블라인드 1개는 비공개로 유지한다. 사용자는 작성자 동의 여부 확인 질문에 진행을 승인했다.

원본: 사용자가 다운로드한 `review_20260910_155704.xlsx` 242개와 판매자센터 과거 리뷰 상세 화면 9개. 엑셀에는 읽기 전용 라이브러리가 A1만 인식하게 만드는 dimension 표기가 있어 실제 worksheet 전체를 읽었다. 과거 9개는 리뷰 고유번호, 본문, 옵션, 평점, 작성일, 사진을 상세 화면에서 확인했다. 과거 9개의 시각은 목록에 표시된 분까지 보존하고 초를 00으로 기록했으며, 공개 화면에는 한국 날짜만 표시한다.

조회 범위: 2025-09-11~2026-09-10 242개, 2024-09-11~2025-09-10 9개. 2021-09-11~2024-09-10은 1년 단위 세 구간 모두 0개. 공개 페이지의 스토어 개설 기간은 4년이다.

리뷰는 원본 상품 번호로 저장하며 다른 색상 상품으로 복제하지 않는다. 같은 모델 리뷰는 공개 상품 상세에서 함께 조회하고 구매 당시 상품명·옵션을 표시한다. No.1884 M, No.0514 Mini와 체스트벨트 세트는 일반 크기·단품과 구분한다. 현재 판매 목록에 없는 제품도 `/reviews.html`에서 원본 구매 상품명과 함께 볼 수 있다. 원본에 리뷰가 없는 제품에는 리뷰를 만들지 않는다.

리뷰 고유번호 중복 삽입을 막고 기존 비공개 상태를 덮어쓰지 않는다. 네이버 리뷰는 `source=naver`, `verified=false`로 보관하며 자사몰 주문을 만들지 않는다. 원문·평점·작성일·첨부 URL을 보존하고 작성자 ID는 마스킹한다. 사진은 네이버 원본 URL을 참조하므로 원본 삭제 시 표시되지 않을 수 있다. 외부 리뷰는 자사몰 검색엔진 구조화 평점에 합산하지 않는다.

공개 화면은 20개씩 전체 리뷰를 추가 조회한다. 관리자 목록은 최근 1000개까지 출처·상품명을 확인하고 공개 여부를 관리할 수 있다. 자동 주기 동기화는 설정하지 않았다.

운영 도구: `scripts/import-naver-reviews.mjs <정규화.json>`으로 검사한 뒤 `--apply`로 가져온다. 데이터와 가져오기 전 DB 백업은 Git 제외 경로 `backups/naver-reviews/`에 보관한다. 원본 주문번호·개인정보는 공개 파일이나 Git에 넣지 않는다.
