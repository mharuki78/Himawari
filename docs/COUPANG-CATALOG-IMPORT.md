# 쿠팡 상품 가져오기

사용자 제공 파일을 모델·색상·미니/M/세트 구성으로 비교한다. 기존 상품의 ID, 가격, 사진, 상세 설명과 재고는 변경하지 않는다. 기존 모델의 추가 색상은 별도 SKU로 추가하고 목록에서 기존 대표 상품을 우선한다. 원본에 색상이 없고 해당 모델이 이미 있으면 중복으로 취급한다.

`node --env-file=.env.local scripts/import-coupang-products.mjs <원본.json>`은 미리보기만 만든다. `--apply`를 붙이면 운영 카탈로그에 추가한다. 작업별 원본 카탈로그·ETag, 계획, 사진, 결과는 Git에서 제외된 `backups/coupang/<시각>/`에 보관한다. 운영 Blob이 없거나 ETag가 없으면 중단한다. 저장 시 읽었던 ETag로 조건부 쓰기하여 다른 관리자 변경을 덮어쓰지 않는다.

수집기에서 판매가와 개당 가격이 합쳐진 정수는 상품명에 실제 표시된 금액과 일치하는 접두부로만 복원한다. 금액을 확인할 수 없으면 중단한다. 같은 모델·색상인데 사진/가격/품절 정보가 다르면 확인 대기로 둔다. 자료에 없는 크기, 무게, 재질, 옵션별 재고는 만들지 않는다.

사진은 원본 쿠팡 CDN의 1,000px 이미지를 확인 후 상품 Blob에 복사한다. 모든 사진을 먼저 내려받고 나서 저장한다. 데이터에는 원본 상품 URL을 유지하며 사이트 구매와 장바구니는 기존 내부 주문 흐름을 사용한다. Npay 공개 범위는 변경하지 않는다.

기존 스키마와 API 호환성을 위해 `naverPrice`는 `price`와 동일한 판매가 저장 필드로 사용한다. 쿠팡 상품을 네이버 가격으로 표시하지 않으며 쿠팡 상품의 `naverDiscountRate`는 비워 둔다. 관리자에서는 원본 URL로 출처를 구분하고 판매가를 수정한다. 쿠팡 가격의 자동 동기화는 하지 않는다.

최초 제공 파일(2026-09-10): 171행, 추가 가능 112 SKU, 기존/파일 중복 57행, No.9004 가격·사진 불일치 2행 확인 대기. 기존 운영 상품은 34개다.
