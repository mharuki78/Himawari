# Himawari 비공개 문의 운영 정책

이 문서는 2026-08-31 사용자 결정에 따라 비공개 문의 기능의 데이터 수명과 접근 범위를 기록한다.

## 수집 항목과 목적

- 이름, 이메일, 문의 제목, 문의 내용을 문의 확인과 답변 목적으로 저장한다.
- 공개 폼은 이 항목의 보관 안내와 필수 동의를 제출 전에 표시한다.
- 광고성 프로필, 전화번호, 첨부파일은 현재 수집하지 않는다.

## 접근 범위

- 문의 목록과 원문은 관리자 인증을 통과한 서버 요청에서만 읽을 수 있다.
- 비밀번호 원문은 코드, Git, Blob, 브라우저 저장소에 보관하지 않는다.
- 비공개 Blob URL을 공개 페이지나 관리자 브라우저에 직접 전달하지 않는다.

## 보관과 삭제

- 문의는 자동 만료 없이 관리자가 개별 삭제할 때까지 보관한다.
- 관리자가 `문의 삭제`를 확인하면 해당 문의 원문과 작성자 정보를 영구 삭제한다.
- 현재 삭제는 복구할 수 없으며 삭제 취소나 휴지통을 제공하지 않는다.

## 운영 경계

- 접수 완료는 비공개 저장 성공만 의미하며 이메일 자동 발송을 의미하지 않는다.
- 관리자는 문의함에 표시된 이메일을 확인해 별도 채널에서 답변한다.
- 이 문서는 운영 결정을 기록하며 법률 적합성 인증을 대신하지 않는다. 보관 목적이나 항목이 달라지면 공개 안내와 이 문서를 함께 갱신한다.
