# 제품 카탈로그 운영 정책

이 문서는 Himawari 공개 제품 카탈로그와 관리자 제품 관리 기능의 운영 기준이다.

## 공개 정보

- 제품명, 모델명, 판매가, 한 줄 소개, 상세 설명, 제품 포인트, 제품 이미지, 스마트스토어 주소는 공개 사이트에 표시한다.
- 가격, 재고, 배송과 실제 구매 조건은 네이버 스마트스토어의 최신 정보를 최종 기준으로 한다.

## 관리자 권한

- 제품 등록, 수정, 삭제는 유효한 Himawari 관리자 세션이 있을 때만 허용한다.
- 공개 사용자는 제품 목록과 상세 정보만 읽을 수 있다.
- 화면에서 버튼을 숨기는 것과 별개로 모든 등록·수정·삭제·업로드 API가 서버에서 관리자 세션을 다시 확인한다.

## 저장과 삭제

- 저장소에 제품 카탈로그가 없을 때는 저장소에 포함된 `products.json`의 기존 제품 목록을 초기 데이터로 사용한다.
- 관리자가 처음 제품을 등록·수정·삭제하면 기존 제품을 포함한 전체 카탈로그를 Public Product Blob에 저장하며, 이후 이 카탈로그가 공개 사이트의 런타임 기준이 된다.
- 기존 제품 수정은 공개 제품 ID와 생성 시각을 유지한다. 새 파일을 선택하지 않은 이미지 영역은 기존 이미지를 유지하고, 새 파일을 선택한 대표 이미지 또는 상세 이미지 영역만 교체한다.
- 예전 등록 기준으로 상세 설명이 짧거나 제품 포인트가 없는 제품도 그 값을 변경하지 않으면 가격 등 다른 항목을 수정할 수 있다. 기존 값을 새로 변경할 때는 현재 검증 기준을 적용한다.
- 모든 수정은 최신 카탈로그 ETag가 일치할 때만 저장한다. 다른 관리자 작업이나 탭에서 목록이 먼저 변경되면 기존 내용을 덮어쓰지 않고 새로고침을 요구한다.
- 제품 삭제는 복구할 수 없는 영구 삭제다. 제품은 공개 목록과 상세페이지에서 즉시 제거된다.
- 관리자 화면에서 해당 제품용으로 업로드한 Blob 이미지는 제품 삭제 후 함께 삭제한다.
- 기존 `products.json`에 포함된 스마트스토어 외부 이미지와 스마트스토어의 원본 제품·이미지는 삭제하지 않는다.

## 업로드 제한

- 대표 이미지 1장과 상세 이미지 최대 5장을 등록할 수 있다.
- 허용 형식은 JPG, PNG, WebP, AVIF다. 대표 이미지는 최대 8MB, 상세 이미지는 장당 최대 15MB다.
- 브라우저의 파일 형식 검사는 편의를 위한 1차 검사이며, 서버가 Blob 소유권·형식·용량을 다시 확인한다.

## 상세페이지 표시

- 상세 이미지는 최대 `56rem` 폭의 한 줄 콘텐츠 레일 안에서 등록 순서대로 이어서 표시한다.
- 각 이미지는 고정 카드 비율로 자르지 않고 원본 가로세로 비율을 유지한다.
- 데스크톱과 모바일 모두 별도 내부 스크롤을 만들지 않고 문서 자체를 아래로 내려 읽는다.

이 정책은 사이트 운영 계약이며 별도의 법률·세무·전자상거래 적합성 검토를 대신하지 않는다.
