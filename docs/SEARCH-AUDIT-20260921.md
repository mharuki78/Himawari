# 홈페이지 검색·AI 정보 구조 보완

사용자가 제공한 2026-09-21 분석 화면(종합 66, SEO 89, GEO 68, AEO 42)을 홈페이지 원문과 대조했다. 외부 도구의 점수·예상 인용은 실제 검색엔진 순위 또는 AI 인용률로 간주하지 않는다.

## 수정한 부분

- 홈페이지에 실제로 읽고 펼칠 수 있는 FAQ 6개를 추가했다. 제품 선택·노트북 수납·소재·관리·A/S 답변과 관련 내부 페이지 링크를 제공한다.
- 같은 질문·답변을 FAQPage 데이터로 제공한다. 단일 페이지의 콘텐츠를 설명하는 목적이며 Google FAQ 특수표시나 AI 인용을 보장하지 않는다. data/home-faq.json과 실제 HTML/스키마 일치를 테스트한다.
- 홈페이지 설명을 제품 종류, 크기·소재 비교, 가이드북·관리 안내를 담은 구체적인 문장으로 바꿨다. OG 설명도 맞췄다.
- H1에 보이는 브랜드명을 추가하고, 브랜드 소개 첫 문장에 히마와리가 제공하는 제품을 명확히 설명했다.
- Organization, WebSite, WebPage를 안정적인 @id로 연결했다. 실제 문의 연락처, 로고, 확인된 공식 채널을 추가했다.
- FAQ 안내 주체와 실제 수정일을 화면에 표시했다. 같은 날짜를 dateModified에 넣었으며 매 요청마다 날짜를 갱신하지 않는다. 홈페이지를 Article로 가장하거나 과거 발행일을 만들지 않았다.
- 홈·브랜드·이야기 목록에서 기존 feed.xml을 RSS alternate로 연결하고 홈에 RSS 구독 링크를 추가했다.
- No.0422 제품 사진에 구체적 대체 텍스트를 보완했다. 장식용 게임 캐릭터의 빈 alt는 접근성 목적에 맞으므로 유지했다. 보고서의 단순 alt 비율을 위해 장식 이미지에 불필요한 설명을 붙이지 않는다.
- llms.txt의 오래된 판매 안내를 현재 홈페이지 구매·비교·가이드북·FAQ·관리·공식 채널로 갱신했다.
- 사용자 제공 공식 네이버 블로그와 플레이스를 홈페이지 원문 링크, 공통 푸터, Organization.sameAs 및 llms.txt에 연결했다. 플레이스 단축 URL은 네이버 지도 2023285629로 이동하며 상호 ‘히마와리코리아’와 사업장 주소가 일치함을 브라우저에서 확인했다.

## 기존에 있던 항목 / 무리하게 바꾸지 않은 항목

- robots.txt, sitemap.xml, llms.txt, Organization/WebSite 데이터가 이미 존재한다. ‘없다’는 일반적 요약을 그대로 적용하지 않았다.
- 상세페이지에는 Product, 상품별 배송·반품·사양 데이터가 있고 이야기 글에는 BlogPosting과 작성자·발행일이 있다. 모든 스키마 타입을 홈페이지에 억지로 넣지 않았다.
- 외부 블로그·플레이스의 소개문이나 관리자 설정, 광고·언론 보도는 변경하지 않았다. 외부에서 자사 홈페이지로 연결하는 링크 여부는 별도 관리 범위다.
- 실제 검색 노출·색인·AI 인용률은 이 변경만으로 측정할 수 없다. 외부 분석 도구 재진단 점수도 확인 전 수치로 보고하지 않는다.
