# 장바구니·주문서 편의 기능

사용자가 승인한 다섯 가지: 총 할인금액, 70,000원 무료배송까지 남은 금액, 선택주문·선택삭제, 장바구니 색상·옵션 변경, 모바일 고정 최종금액·주문 버튼.

선택은 브라우저의 장바구니 UI 상태이며 회원 장바구니의 상품을 지우지 않는다. 새 상품은 기본 선택한다. 선택하지 않은 상품은 주문서와 Npay 요청에서 제외하고, 실제 구매 후에도 남긴다. 모두 해제하면 주문하지 않는다.

선택한 유효 상품의 실제 판매가로 소계와 기본 배송비를 계산한다. 확인한 행사 정상가와 단가 차이만 혜택으로 합산한다. 주문서 쿠폰 할인은 별도 계산하고 행사 할인과 이중 차감하지 않는다. 기본 배송비3,500원·무료배송 기준70,000원은 기존 정책 모듈을 재사용한다.

옵션 변경은 기존 카탈로그의 같은 모델 품목·옵션에서 선택한다. 일반 상품은 정상 판매 조건을 유지하며, 행사 상품은 현재 열린 행사에 포함된 옵션만 변경한다. 변경 전 최신 상품·행사를 다시 읽고 수량·품절·종료·가격을 검증한다. 같은 구매 조건의 기존 SKU와 합치면 수량을 더하고 한도를 넘으면 변경하지 않는다. 다른 구매 조건과는 자동 병합하지 않는다.

모바일 하단에는 배송비를 포함한 최종금액과 명확한 다음 행동을 표시한다. 결제 방법을 선택하기 전에는 방법 선택으로 이동하고, 선택한 뒤에는 기존 주문 제출을 사용한다. 폼을 가리거나 키보드·안전영역·확인창·완료 화면과 충돌하지 않게 한다. 실제 결제나 고객·회원 개인정보 사용 없이 새 Chrome 컨텍스트의 공개 상품으로 검증한다.

현재 체크아웃의 행사 유효성·쿠폰 제한·실제 주문 서버 검증을 유지한다. 사용자 승인 범위에서 이번 파일만 커밋·push하고 정확한 production READY와 운영 모바일 결과를 확인한다.
