# 이야기 전체 개정과 다음 발행 기준

2026-10-14 사용자 요청: 기존 이야기 전체를 더 길고 구체적인 매거진 글로 개정하고 사진을 추가한다. 2026-10-15부터 LookBook 구도와 이야기 형식의 반복을 줄인다. 사용자는 제품·생활을 섞은 매거진 방향을 선택했다. 작성·이미지·업로드·배포는 이미 승인됐다.

## 기존 이야기

- 149편의 기존 URL, 게시일, 대표 이미지를 유지한다. 제목·요약·본문·FAQ는 개정할 수 있다. 실제 확인된 사실만 사용한다.
- 본문은 한국어 2,400~4,500자를 목표로 한다(최소 2,400자). 의미 없는 분량 채우기를 금지하고 구체적인 예시·이유·상황별 차이로 충분히 설명한다.
- 같은 4단계 준비 요령을 반복하지 않는다. 설명형·비교형·선택형·장면 중심·기록/해석형을 주제에 맞춰 구성한다. 고정 FAQ 2개와 반복 결론은 없앤다.
- 기존 대표 사진에 실제 해당 제품 원본 사진 1장 이상을 본문에 추가한다. 원본 출처와 정확한 제품 링크를 표시한다. 의미 없는 장식 사진이나 다른 모델로 대체하지 않는다.
- 처음부터 모델을 특정하지 않은 일반 주제 글은 실제 제품을 새 예시로 선택할 수 있다. 이전 대표 사진의 모델을 임의로 식별했다고 주장하지 않는다.
- 확인할 수 없는 창업 경험·고객 인용·제작 기간·실측·기능 주장은 만들어내지 않는다. 처음 두 브랜드 글도 공개된 브랜드 정보만 사용한다.

## 다음 날부터 이야기

- 오전 3편 유지. 글마다 기본 사진 3장: 서로 다른 역할의 새 imagegen 사진 2장과 실제 제품 사진 1장. 하루 신규 생성 이미지는 최소 6장이다.
- 글마다 한국어 본문 2,400자 이상과 실제 추가 이미지 2장 이상을 확인한다. 모든 글을 같은 구조나 FAQ로 맞추지 않는다.
- 최근 제목뿐 아니라 핵심 질문·논지·형식도 비교한다. 같은 주제의 사례만 바꾸어 재발행하지 않는다.
- 원본 직접 검토·검증된 치수·AI 표시·웹 최적화·운영 READY 및 브라우저 검증은 유지한다.

## 다음 날부터 LookBook

- 기존 사진은 유지. 하루 2장 유지.
- 매일 적어도 두 가지 촬영 방식 중 하나를 뚜렷하게 바꾼다: 측면/앞쪽을 포함한 전신, 허리 위 근접, 손으로 들기/어깨에 걸치기(제품 구조에 맞게), 앉기/움직이기, 인물과 소품/활동이 보이는 환경 컷.
- 매일 뒤로 돌아서 가방을 보여주는 컷 2장을 만들지 않는다. 최근 14일에는 구도·가방 크기·인물의 화면 점유·카메라 거리도 기록하고 비교한다.
- 카탈로그 촬영, 자연스러운 거리 사진, 활동 장면, 소재/디테일을 강조한 착용 컷을 순환한다. 장소·옷 색만 바꾸는 반복을 금지한다.
- 로고·형태·색·포켓·끈·비율과 실제 착용 방식은 항상 보존한다. 짧고 자연스러운 한국어 설명과 확대 보기의 AI 표시는 유지한다.

## 검증

본문 길이·중복 문단·추가 이미지·모델 매핑·날짜·메타데이터·링크·파일 존재를 전체 149편에 검사한다. 주제별로 실제 본문을 다시 읽고 PC·모바일의 긴 글, 본문 사진, 표, FAQ를 확인한다. 변경 파일만 커밋·push하고 정확한 커밋의 운영 READY와 실제 사이트를 확인한다. 미래 기준은 기존 예약의 이름·종류·상태·시간·대상·알림 설정을 보존한 프롬프트 변경으로 적용한다.
