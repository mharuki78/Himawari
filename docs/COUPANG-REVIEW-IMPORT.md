# 쿠팡 리뷰 가져오기

2026-09-10 현재 카탈로그와 연결된 쿠팡 상품 페이지 31개를 브라우저에서 확인했다. 공개 리뷰 616개(모델·크기 구분 26개), 첨부 이미지 423개를 수집했다. 제목이나 본문이 있는 리뷰는 197개이며 나머지는 별점 리뷰다. 영상 첨부는 페이지에서 제공한 미리보기 이미지를 보존하며 원본 상품 페이지에서 영상을 확인할 수 있다.

No.1084H는 총 39개 표시에 실제 공개 목록 38개, No.2513은 총 2개 표시에 실제 공개 목록 1개였다. 전체 페이지 및 No.2513 최신순을 확인했으며 공개되지 않은 두 건은 만들거나 평점에 합산하지 않는다. No.124와 No.0422는 100개 이후 페이지까지 확인했다. 리뷰 없는 상품에도 기록을 만들지 않는다.

원본은 `backups/coupang-reviews/browser-pages.json`, 상품 연결 자료는 같은 폴더의 `normalized-input.json`에 보관한다. 이 폴더는 Git에서 제외한다. DOM에 표시된 리뷰 번호, 작성일, 별점, 구매 상품명, 판매자, 제목, 본문, 첨부 URL을 사용한다. 날짜만 공개되어 있으므로 한국 시간 자정으로 저장하며 화면에는 날짜만 표시한다. 체험단 무료 제공 안내와 낮은 평점도 그대로 유지한다. 작성자는 마스킹하며 이름이 없는 경우 비공개 작성자로 표시한다.

`node --env-file=.env.local scripts/import-coupang-reviews.mjs <정규화.json>`으로 검증한 뒤 `--apply`를 붙여 반영한다. 운영 카탈로그의 원본 URL과 모델을 대조하며, 저장 전 리뷰 DB와 정규화 결과를 날짜별 폴더에 백업한다. `(source, source_review_id)` 고유 제약과 `DO NOTHING`으로 재실행 중복 및 기존 비공개 상태 덮어쓰기를 막는다.

리뷰는 한 번만 저장하고 같은 모델의 색상에서 함께 조회한다. No.124/124S 등 크기, 세트 구분을 유지하며 구매 당시 색상·상품명과 판매자를 표시한다. 과거 상품명에 모델이 없는 경우에는 단일 모델임을 확인한 원본 상품 URL로 연결한다. `source=coupang`, `verified=false`이며 자사몰 구매 확인이나 주문을 생성하지 않는다. 검색엔진 구조화 평점에는 기존과 같이 자사몰 구매 확인 리뷰만 포함한다.

공개 페이지와 관리자에 쿠팡 출처를 표시하며 원본 리뷰 영역 링크를 제공한다. 사진은 쿠팡 원본 URL을 참조하므로 원본 삭제 시 표시되지 않을 수 있다. 자동 주기 동기화는 설정하지 않았다.
