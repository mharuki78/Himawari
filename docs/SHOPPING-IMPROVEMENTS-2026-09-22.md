## 변경

- 제품 목록: 중복 대형 소개/대표 상품 섹션을 걷고 검색·정렬·용도 필터를 상단에 배치. 색상 3개 미리보기와 전체 옵션 펼치기, 색상/크기/구성 구분. 목록 카드에서 상세·비교를 주 행동으로, 관심상품은 사진 위 버튼으로 제공.
- 비교: 최대 3개 선택을 브라우저에 유지. 목록·추천·가이드북·상세의 비교 버튼 연결. 모델 먼저 선택 후 실제 판매 옵션 선택, 같은 항목 숨기기, 같은 용도/가격 ±30%의 판매 구성 제안.
- 상세: 실제 등록 무게/외부 치수/노트북 수납칸과 배송/리뷰를 가격 아래 요약. 사양·사진·리뷰·배송 바로가기. `<base href="/">`로 인한 제품 앵커의 홈 이동 방지. 등록 소재·생활방수·수납칸을 제품 포인트로 사용.
- 크기 안내: 확인된 가로×세로×폭으로 A4와 크기를 비교하는 도식. 외부 치수이며 실제 수납을 보장하지 않는다고 명시. 기존 실물 제품 사진 유지. 착용자 키 및 새로운 실측/수납 촬영 자료는 없으므로 생성하거나 추정하지 않음.
- 추천: 구매 가능한 실제 구성에 엄격한 예산 적용. 등록된 무게/용량/내부 치수에 근거한 이유 2개와 확인점. 0~2개 결과도 정직하게 표시하고 조건 완화/초기화 제공. 추천 시작·완료·제품 클릭 이벤트 추가(기존 수집 함수 사용).
- 주문서: 주요 안내/오류/동의 문구 14px, 어두운 hover의 밝은 글씨, 수량 버튼 44px.
- 가이드북: 모델·목차 검색, 현재 장의 검증된 모델 페이지 매핑과 카탈로그 사양, 실제 제품/비교 연결. 확인되지 않은 H1084와 1084H는 매칭하지 않음.
- 이야기: 제목·요약·태그 검색과 출근/통학/여행·외출/관리 필터, URL 상태, 초기화/빈결과. 제품 사양 영역에서 해당 모델을 다룬 이야기 연결.
- 히어로: 기존 9007 영상 유지, 실제 poster와 preload 불일치 수정.

상품 원본 사양·가격·재고·주문·결제·로그인 설정은 변경하지 않음. 새 외부 메시지/주문은 제출하지 않음.
