# Npay 기술지원 문의 초안

상태: 사용자 승인 후2026-11-13 공개 게시 완료. [Npay Q&A #222](https://github.com/npay-mall-order-api/merchant-order-api/discussions/222). 로그인하지 않은 화면에서도 제목·본문을 확인했습니다. 게시 확인 근거는 `backups/npay-campaign-2026-11-13/support-discussion-receipt.json`입니다.

게시 위치: Npay 주문형 가맹점 API 기술지원 GitHub의 Q&A.

제목: 주문형2.1 한정수량 상품의 재고 예약과 BUY_KEY 재사용 처리 문의

안녕하세요. 자사몰에서 일반 주문과 Npay 주문이 같은 실물 재고를 사용하고, 일부 상품에는 기간과 판매 수량이 정해진 행사가를 적용하려고 합니다. 샌드박스 애플리케이션을 발급받아 주문관리 API1.11.0 문서와 주문등록2.1 가이드를 확인했습니다.

한정수량을 정확히 지키기 위해 아래 동작을 확인하고 싶습니다.

1. 주문등록으로 받은 BUY_KEY를 다시 열거나 여러 창에서 사용하면 여러 주문·결제가 만들어질 수 있나요? 재사용 제한, 유효기간, 가맹점 측 폐기·취소 방법이 문서화된 곳이 있다면 알려주세요.
2. 상품정보 응답의 stockQuantity 및 옵션 조합 재고에 대해 Npay가 동시 결제를 원자적으로 예약·차감하나요? 최종 결제 전에 가맹점이 재고를 확정할 수 있는 인증된 콜백이나 별도 API가 있는지도 궁금합니다. 상품정보 GET 자체를 주문이나 결제 이벤트로 처리하지 않으려 합니다.
3. 행사 종료 후 이미 열린 주문서·보관함에서 이전 행사가로 결제되는 것을 막으려면 어떤 공식 절차를 사용해야 하나요? 상품정보의 NOT_SALE 응답으로 최종 결제까지 차단되는지 확인 부탁드립니다.
4. 주문등록 후 결제하지 않은 건에 대해 가맹점이 확보한 수량을 언제 반환할 수 있는지, 결제가 더는 성립하지 않음을 확인하는 공식 상태·만료 신호가 있나요? 임의의 시간 제한으로 재고를 반환하지 않으려 합니다.

상품주문 변경 내역·상세 조회 API를 통한 결제·취소 동기화는 별도로 구현할 예정입니다. 위 예약·재사용 계약에 맞는 방식으로 샌드박스 개발과 검수를 진행하고 싶습니다. 참고할 공식 문서나 권장 흐름을 안내해 주시면 감사하겠습니다.
