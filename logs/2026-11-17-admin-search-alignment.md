## 원인과 구현

제품 목록 제목에는 좌우 여백이 있으나 검색 폼은 가로 여백 없이 패널 테두리에 붙어 있었다. 검색 컨트롤은 줄바꿈 가능한 flex여서 좁은 화면의 배치도 일정하지 않았다.

기존 관리자 색상·서체·버튼 모양을 유지하고 검색 폼의 여백을 제목과 맞췄다. 넓은 화면은 검색 입력창·검색·전체 보기의 세 열, 600px 이하에서는 입력창 한 줄과 같은 너비의 버튼 두 개로 배치한다. 컨트롤의 최소 높이는 48px이며 설명 문구도 입력창과 같은 선에서 시작한다. CSS 캐시 버전을 갱신했다. 검색 API와 상품 데이터는 변경하지 않았다.
