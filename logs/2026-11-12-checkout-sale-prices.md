# 주문서 블랙 프라이데이 가격 표시

- 날짜·작성자·작업 ID: 2026-11-12 Asia/Seoul · Codex · checkout-sale-prices-20261112
- 사용자 요청: 주문서에도 블랙 프라이데이 상품의 정상가 취소선·행사가·할인율을 함께 표시한다.
- 구현: 검증한 행사 API의 정상가·종료일을 화면 표시 정보로 연결한다. 바로 구매·장바구니·회원 장바구니 복원은 같은 품목 검증 함수를 사용한다. 주문 요청의 구매 식별자·확정 행사 단가·수량 형식은 유지한다.
- 표시: 행사 상품에 개당 정상가 취소선, 개당 행사가, 할인율을 표시하며 수량을 곱한 상품금액을 구분한다. 일반 상품은 기존 판매 금액을 표시한다.
- 종료·재개: 주문서를 열어 둔 채 행사가 끝나면 상품·할인 표시를 지우고 다시 확인하도록 안내한다. 기간 연장 후 다시 시도에 성공하면 주문 버튼을 복구하며, 이미 주문 요청이 진행 중이면 비활성을 유지한다.
- 검증: 실제 렌더러로 바로 구매와 혼합 주문의 개당 금액·할인율·수량 변경·합계를 확인했다. 열린 주문서의 종료와 기간 연장 후 재시도 회귀를 실패시킨 뒤 통과시켰으며 독립 검토의 재시도 지적을 수정하고 재승인을 받았다. 최종 전체 테스트·운영 배포 근거는 아래 receipt로 기록한다.
