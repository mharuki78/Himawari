## 원인과 구현

메뉴 아이콘은 앞의 네 링크에만 붙고 있었다. 나머지 네 링크에도 같은 Phosphor 계열 아이콘을 추가했다. 헤더 검색·회원·장바구니·스토어·메뉴는 마우스 오버와 키보드 포커스 때 설명을 표시한다. 설명은 마우스로 가리킬 수 있고 Escape로 닫힌다. 회원·장바구니·메뉴 상태가 바뀌면 설명도 갱신한다. 메뉴가 좁은 화면에서 넘치지 않도록 1320px에서 모바일 메뉴로 전환한다.

고정 0422 HTML이 무작위 카탈로그와 사진을 기다리는 동안 먼저 보이고 있었다. 스크립트가 활성화된 첫 화면에는 중립적인 로딩 안내를 표시하고, 실제 사진을 디코딩한 뒤 제품·색상·링크를 함께 공개한다. 요청·사진·화면 스크립트 실패에는 복구 동작을 제공한다. JavaScript가 꺼져 있으면 실제 0422 사진과 전체 제품 링크를 유지한다.

서로 다른 기존 CSS 규칙이 섹션 폭과 버튼을 제어하고 있었다. 홈페이지만 `.home-page`로 구분해 최대 1320px와 공통 좌우 여백을 적용했다. CTA 문구와 화살표는 가운데 정렬하고 제품 카드의 하단 버튼, 릴스 제목의 간격과 기준선을 맞췄다. FAQ의 내부 여백은 유지한다.

사용자의 제안을 반영해 캠페인 영상을 첫 화면 다음 섹션으로 옮겼다. 별도의 No.1027 착용 영상은 제품 목록 다음에 유지해 두 영상이 연속으로 반복되지 않도록 했다. 홈 게임 소개는 기존 두 번째 게임인 `rhythm.html`과 실제 사용 중인 No.1884 게임 그래픽으로 교체했고, 0422 어드벤처 링크는 유지했다.

## 검증과 근거

- UI 빌드 성공. 회귀 테스트 전체 결과는 `backups/home-ui-refinement-2026-10-31/full-tests.txt`에 보존한다.
- 실제 Google Chrome에서 1440·390·320px 화면을 검수했다. 1920·1366·1320·1024px의 헤더와 가로 넘침도 확인했다. 주요 섹션의 좌우 기준선, 제품 카드 하단 버튼과 릴스 제목의 위치를 실측했다.
- 지연된 카탈로그에서 고정 0422 사진·모델이 보이지 않는 것, 실제 사진과 정보가 함께 공개되는 것, 첫 사진 실패 후 재시도, 스크립트 실패 후 다시 불러오기, JavaScript 비활성화 때의 정적 사진을 확인했다.
- 설명의 마우스 오버·포커스·Escape·설명 위로 이동, 모바일 메뉴 8개와 Escape 포커스 복귀, 장바구니·회원·스토어 선택을 확인했다. 주문이나 로그인 설정을 변경하지 않았다.
- 독립 리뷰에서 발견한 화면 스크립트 실패 및 본문 파싱 지연의 복구 경로를 보완했다. 이전 게임 미리보기의 사용하지 않는 초기화 코드도 제거했다.
- Impeccable 검사 원본은 `layout-before.json`·`layout-after.json`에 있다. 남은 4개 경고는 실제 렌더링과 대조했다. 공지 문구는 중앙에 있고, 영상 영역은 의도한 사진 가장자리이며, 릴스 헤더와 FAQ는 각각 헤더 하단 여백과 summary 내부 여백으로 읽기 간격을 확보한다. 이 경고는 화면에서 관찰한 문구 잘림을 뜻하지 않는다.
- Figma 연결은 확인했지만 프로젝트 Figma 파일 참조는 없었다. 기존 `DESIGN.md`, 승인한 시안, 실제 Chrome 화면을 기준으로 수정했다. Anime.js·daisyUI는 기존 로컬 의존성과 빌드를 재사용했다.
