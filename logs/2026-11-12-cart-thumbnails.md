# 장바구니 상품 사진과 행사 가격 표시

- 날짜·작성자·작업 ID: 2026-11-12 Asia/Seoul · Codex · cart-thumbnails-20261112
- 사용자 요청: 모든 장바구니 품목에 상품 썸네일을 표시하고, 블랙 프라이데이 품목에 정상가 취소선·행사가·할인율을 함께 표시한다.
- 구현: 공개 상품 API와 일치하는 행사 API에서 사진과 표시 정보를 불러온다. 기존 저장·회원 복원 장바구니에도 적용하며, 구매 식별자·확정 행사 단가·수량은 그대로 유지한다. 썸네일을 누르면 해당 상품 상세로 이동한다. 사진이 없거나 불러오지 못하면 준비 중 표시를 사용한다.
- 종료 처리: 확인된 행사 종료 시각에 타이머가 가격·취소선·할인율을 지우고 행사 품목을 재확인 상태로 전환한다. 잠긴 구매 단가는 보존한다. 종료 응답·가격 변경·품절도 기존 검증에 따라 구매를 차단한다.
- 화면: 기존 디자인을 유지하고 사진·상품 정보·삭제·수량을 격자로 배치했다. 변경한 수량·삭제 버튼의 터치 영역은 44×44px 이상이다. 모바일 320px·390px와 PC 1440px에서 가로 넘침과 사진 로딩을 확인했다.
- 검증: 기존 저장 장바구니의 사진·정상가·행사가·할인율 및 종료 처리 회귀를 먼저 실패시킨 뒤 통과시켰다. 독립 코드 검토에서 발견된 열린 장바구니의 행사 종료 표시 문제를 수정하고 재검토 승인을 받았다. 최종 전체 테스트와 운영 배포 결과는 아래 완료 근거에서 확인한다.
- 실제 공개 상품 시나리오: 행사 No.1027 라벤더49,000원×2(정상가94,000원·48%), 행사 No.0422 블루39,000원×1(정상가76,000원·49%), 일반 No.1088M+체스트벨트 SET75,800원×1. PC·모바일 장바구니와 주문서 합계212,800원, 배송비0원, 새로고침 뒤 동일 결과를 확인했다.
